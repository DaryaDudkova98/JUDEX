# JUDEX

Судебная унифицированная система управления долгами и их исполнения с элементами экспертной системы.

---

### Menu

- Главная / Dashboard
- Должники / Debtors (до передачи юристам)
- Требования / Requirements (отправлены требования)
- Судебное производство / Judicial Production (иск подан, госпошлина оплачена, решения нет)
- Судебное взыскание / Judicial Recovery (поступили взыскания из ОПИ)
- История оплат / Payment History
- Отчеты / Reports
